# CardTool

Собственная прошивка-оболочка для **M5Stack Cardputer ADV** с внешним экраном **ILI9341**: лаунчер с группами приложений, единый стиль интерфейса, настраиваемые темы и модульная архитектура, в которой каждое приложение это отдельный файл.

## Возможности

- **Лаунчер с группами**: Учёба, Игры, Хакинг, Система. Пустые группы скрываются автоматически.
- **Единый стиль интерфейса** (`src/ui.h`): заголовок, строки списка, подсказки по клавишам. Все приложения выглядят одинаково.
- **Темы и настройки**: 4 темы (тёмная, светлая, синяя, янтарь), 8 акцентных цветов, поворот экрана, инверсия. Настройки применяются сразу и сохраняются в энергонезависимой памяти.
- **Модульные приложения**: одно приложение = один класс = один файл. Добавление новой программы занимает две строки в реестре.
- **Кириллица** во всём интерфейсе.
- **Экономная работа с ОЗУ**: без полноэкранного буфера, отрисовка напрямую в экран.
- **SD-карта** на общей шине с экраном для данных приложений (тексты, таблицы).

## Оборудование

- M5Stack Cardputer ADV (ESP32-S3, 8 МБ flash, без PSRAM, клавиатура на TCA8418)
- Дисплей ILI9341 240x320 (используется горизонтально, 320x240)
- microSD-карта (по желанию)

### Подключение экрана (разъём EXT)

| Сигнал экрана | Пин Cardputer |
|---|---|
| CS | G5 |
| RST | G3 |
| DC | G6 |
| MOSI (SDI) | G14 |
| SCK | G40 |
| LED | 3.3V (подсветка всегда включена) |
| MISO | не используется |

Экран делит шину с SD-картой (SCK=G40, MISO=G39, MOSI=G14, CS=G12). Если SD или экран работают нестабильно, перенеси MOSI и SCK экрана на G13 и G15 и поменяй пины в `src/config.h`.

| Действие | Клавиши |
|---|---|
| Вверх / вниз | Fn + `;` / Fn + `.` |
| Влево / вправо | Fn + `,` / Fn + `/` |
| Выбор, подтверждение | Enter |
| Назад, выход из приложения | Fn + `` ` `` (Esc) |
| Стереть символ | Del |

В списках стрелки работают и без Fn.

## Сборка и прошивка

Требования: [PlatformIO](https://platformio.org/) (CLion или VS Code), Python 3.11 или 3.12, платформа pioarduino.

```bash
# сборка
pio run -e cardputer

# сборка и прошивка по USB
pio run -e cardputer -t upload
```

Для прошивки по USB зажми кнопку G0 при включении Cardputer, чтобы он вошёл в режим загрузки. После заливки нажми reset.

Готовый файл прошивки: `.pio/build/cardputer/firmware.bin`. Его можно копировать на SD-карту и запускать из загрузчика. На Windows копируй файл командой «Копировать», а не двойным кликом: система монтирует `.bin` как диск и блокирует файл.

## Как добавить приложение

1. Скопируй `src/apps/template.h` в `src/apps/имя.h`, переименуй класс и функцию `create...`.
2. В `src/registry.cpp` добавь `#include "apps/имя.h"`.
3. Добавь строку в `kApps`: `{"Название", "Группа", createИмя},`. Группа должна быть из списка `kGroups`.

Жизненный цикл приложения:

| Метод | Когда вызывается |
|---|---|
| `start()` | при входе |
| `onKey(e)` | при нажатии клавиши |
| `update(ms)` | каждый цикл (таймеры, игры) |
| `draw()` | после `invalidate()` |
| `stop()` | при выходе |

Выход из приложения: `requestExit()`.

## Стиль интерфейса

- Цвета только из темы: `C_BG`, `C_FG`, `C_DIM`, `C_ACCENT`, `C_SEL`, а также `C_OK` и `C_ERR` для статусов.
- Заголовок через `ui::titleBar()`, строки через `ui::row()`, подсказка внизу через `ui::footer()`.
- Один шрифт с кириллицей (`UI_FONT`).
- Подсказка по клавишам на каждом экране.

Для разработки отдельных приложений в нейросети есть готовый промпт `PROMPT_new_app.md`: он описывает архитектуру, стиль и ограничения проекта.

## Частые проблемы

| Проблема | Решение |
|---|---|
| Сборка не видит код | Исходники должны лежать строго в папке `src` |
| `Failed to install Python dependencies into penv` | Удалить `%USERPROFILE%\.platformio\penv`, использовать Python 3.11 или 3.12 |
| Ошибка `narrowing conversion` | Флаг `-Wno-narrowing` (уже есть в `platformio.ini`) |
| Конфликт имён макросов с библиотеками (FP, SHIFT) | Переименовать или вынести через `build_src_flags` |
| В M5GFX нет панели ILI9341 | Панель описана в `src/display.h` (`Panel_ILI9341_Local`) |
| Зеркальное или перевёрнутое изображение | Поворот в «Настройках» (значения 1, 3, 5, 7) |
| Перепутаны цвета или инверсия | `rgb_order` и `invert` в `src/display.h`, либо инверсия в «Настройках» |
| Экран рябит | Уменьшить `TFT_FREQ` в `src/config.h` до 20000000 |
| Глючат SD или экран | Перенести пины экрана на G13 и G15 |
| Кракозябры в русских комментариях | Сохранять файлы в UTF-8 |

## Технические ограничения

- ~320 КБ ОЗУ, PSRAM нет: полноэкранный 16-битный буфер (~150 КБ) не используется.
- Тексты, таблицы и данные приложений хранятся файлами на SD или во flash.
- Формулы (степени, индексы, дроби, греческие буквы) отрисовываются вручную.
- Кнопок мало: функции раскладываются по слоям Fn.
